# 📝 Todo App

A simple, clean, and responsive Todo App built using **HTML, CSS, and JavaScript**. The application allows users to add tasks with due dates, display them dynamically, and remove completed or unwanted tasks through an intuitive interface.

## ✨ Features

- ➕ Add new tasks
- 📅 Assign due dates to tasks
- 🗑️ Delete tasks instantly
- ⚡ Dynamic task rendering with JavaScript
- 📱 Responsive and clean user interface
- 🎨 Modern and minimal design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Todo-App/
│── index.html
│── todo.css
│── todo.js
└── README.md
```

## 📖 How to Use

1. Enter your task.
2. Select a due date.
3. Click **Add**.
4. Your task will appear in the list.
5. Click **Delete** to remove a task.
